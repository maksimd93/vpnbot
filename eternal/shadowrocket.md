# WARP → Eternal в Shadowrocket

На 01.11.2026 в App Store опубликован Shadowrocket 2.2.93. История разработчика
подтверждает AmneziaWG (включая Junk Manager), XHTTP и proxy chains.
Само приложение iOS в этой среде недоступно: импорт и работа на iPhone пока
не проверены. Сетевой эквивалент подготовленного профиля проверен ядром LxBox.

## Настройка

1. Обновить Shadowrocket.
2. Бот → VLESS → пользователь → **Ускоренный WARP** → **Настроить Shadowrocket**.
3. Шаг 1: скопировать весь WireGuard-блок, импортировать из буфера в Shadowrocket,
   сохранить имя **WARP-SR**. В блок уже включены ключ и CPS-маскировка.
4. Шаг 2 в боте: скопировать VLESS-ссылку и импортировать узел **Eternal-SR**.
5. В Shadowrocket у **Eternal-SR** открыть ⓘ → **Через прокси / Proxy Through**,
   выбрать **WARP-SR**, сохранить. Выбрать **Eternal-SR** для подключения.
6. Для первой проверки выбрать **Глобальная маршрутизация → Прокси**.

Направление: телефон → WARP-SR → Eternal-SR → интернет. Если выбрать WARP-SR
как конечный узел, это будет самостоятельный WARP, а не выход через Eternal.
VLESS идёт на исходный адрес Eternal: версия «резерв 443» с Funnel для этой
цепочки не нужна, иначе её ограничение скорости сохранится.

## Реализация

- Отдельная регистрация WARP для Shadowrocket. Ключ LxBox не используется;
  эти два устройства могут работать одновременно. Каждая регистрация —
  для одного устройства, синхронизировать её на несколько активных устройств нельзя.
- `ip=quic,id=www.google.com,ib=chrome` из LxBox — его синтаксический вариант
  генерации пакета. Для переносимого `.conf` создан стандартный `I1=<b 0x...>`:
  синтетический QUIC Initial длиной1250байт получен тем же ядром на loopback,
  с одноразовыми фиктивными WG-ключами. Посторонний трафик не перехватывался.
- I1 в этом экспорте фиксирован для профиля. Это не динамическая генерация
  нового пакета при каждом запуске приложения; при необходимости профиль
  можно перевыпустить с новой сигнатурой.
- Остальные значения соответствуют проверенному маршруту:188.114.97.1:500,
  MTU1280, keepalive25, Jc4/Jmin40/Jmax70, S1=S2=0, H1..H4=1..4.
- Секреты хранятся только в `pac.json.eternal_warp.shadowrocket`:
  `uuid`, `wireguard_conf`, `vless_uri`. Выдача наследует проверку пользователя
  и состояния основного WARP-профиля; дополнительно проверяется UUID в URI.
  У бота два экрана, чтобы оба импорта укладывались в лимит Telegram.
- Проверен холодный старт с отдельным ключом и явным I1 через физический Wi-Fi:
  выход146.103.110.71,10МБ за1,448с, ещё3/3 HTTPS-запроса. Это тест сетевого
  формата ядром sing-box-lx, не замер Shadowrocket и не гарантия его скорости.
- Проверены PHP lint, offline-тесты навигации/изоляции/HTML-экранирования CPS,
  реальные экраны с production-данными:3064 и594 символа соответственно.
  Telegram API не вызывался; пользователь получает импорт нажатием кнопки.

Источники совместимости и синтаксиса:
- История разработчика: https://apps.apple.com/us/app/shadowrocket/id932747118
- Оригинальное руководство с примерами импорта и направлением Proxy Through:
  https://github.com/LOWERTOP/Shadowrocket/wiki/
- CPS/I1: https://docs.amnezia.org/documentation/amnezia-wg/

Для скрытия только этих импортов удалить `eternal_warp.shadowrocket` из PAC;
это не отзывает ключ, уже сохранённый на устройстве. Полный отзыв — DELETE
соответствующей регистрации WARP по её приватному API-токену.
