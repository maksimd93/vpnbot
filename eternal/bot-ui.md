# Интерфейс Telegram-бота Eternal

По умолчанию `/start` и `/menu` сразу показывают статусы сервисов Eternal и меню:

- **📱 Подключить устройство** — устройство → приложение → набор подключений → файлы и инструкция.
- **📘 Помощь с подключением** — приложение → название импортированного набора → инструкция; отдельно проверка связи.
- **⚙️ Управление сервером** — пользователи VLESS, прежние протоколы, маршрутизация, DNS, подписки и настройки.
- **🔄 Обновить статусы** — повторно проверить процессы и обновить главный экран.
- **↩️ Старый интерфейс** — прежнее главное меню со всеми его разделами.

Готовые наборы доступны для LxBox и Exclave на Android, Shadowrocket на iOS,
v2rayN на Windows и Karing на Android/iOS.
«Eternal · Авто» и «Eternal · WARP-выход» выдаются существующими обработчиками;
перестройка меню не меняет файлы, ключи, маршруты или серверные службы.
Инструкции уточняют импорт и выбор группы: получение файла само по себе VPN не включает.
Для других компьютеров, роутеров и приложений доступны настройки протоколов.
В подключении отмечен текущий шаг. После выбора режима кнопка «Назад»
возвращает к приложениям выбранной платформы. Раздел протоколов возвращает
именно туда, откуда его открыли. Инструкция после получения файла возвращает
к режимам, инструкция из помощи — к выбору инструкции. На каждом экране есть
отдельная кнопка **🏠 На главную**.

## Комплекты и инструкции для пересылки

В меню **Подключить устройство** есть Android, iPhone/iPad и Windows. Выдача
отправляет файлы и одно самостоятельное сообщение в личный чат инициатора.
Получателю нужно переслать их вместе; доступ к боту и кнопкам меню ему не нужен.
Инструкция включает ссылку на установку, точные имена файлов, импорт, выбор
подключения, разрешение VPN, проверку выхода и исправление распространённых ошибок.
Кнопка **📤 Инструкция для пересылки** повторяет только текст без перевыдачи ключей.

Для каждого клиента есть инструкции по обычному выходу и серверному WARP.
Karing и v2rayN получают отдельные TXT со стандартными URI; эти TXT не создают
автоматическую группу. В пошаговом сценарии выбран конкретный узел нужного набора.
LxBox сохраняет авто-узел в JSON, Exclave — настройку балансировщика, Shadowrocket —
два файла и группу `url-test`. Содержание прежних клиентских файлов сохраняется.

Ответ Telegram проверяется для каждого документа и инструкции. При неполной
доставке бот не показывает успешную выдачу, а предлагает повтор и запуск личного чата.
Просмотр инструкций не меняет настройки VPN. Старый интерфейс доступен по-прежнему.
Ссылки и границы проверки — [источники инструкций](client-guides-sources.md),
формат новых файлов — [переносимые наборы](client-exports.md).

## Статусы на главном экране

Бот получает снимки контейнеров и процессов через локальный Docker API.
Запросы только читают данные; параллельная проверка имеет ограничение времени.
SSH и запуск команд внутри контейнеров для этого не используются.

- 🟢 Процесс запущен.
- ⚪ Контейнер или ожидаемый процесс остановлен.
- ➖ Сервис не установлен.
- 🟠 Контейнер требует внимания, например перезапускается или имеет нездоровый статус.
- ❔ Нет достоверных данных о состоянии.

Отсутствие данных не выдаётся за остановку. Для WireGuard без процесса в userspace
показывается неопределённое состояние: интерфейс может обслуживаться ядром.
**WARP-выход** — текущий отдельный выход Eternal; **WARP-прокси** — прежняя отдельная
служба. Их статусы не смешиваются. Зелёная отметка подтверждает процесс на сервере,
но не доступность VPN с телефона или работу интернета через него.

## Технические разделы

В новом интерфейсе VLESS / Xray разделён по задачам: пользователи и ссылки,
подключения, контроль устройств и IP, статистика, ссылки и шаблоны. Выбранный
транспорт подписан и повторным нажатием не переключается. Фильтры пользователей
работают только в текущем меню и не записывают PAC. Списки сохраняют исходные
индексы пользователей при фильтрации и пагинации.

Пояснения соответствуют действиям кода:

- Основной транспорт меняет общий вход VLESS; gRPC / REALITY — дополнительный вход.
- Контроль нескольких IP отправляет уведомления, не блокирует пользователя автоматически.
- HWID проверяется при получении подписки; уже импортированный ключ этим не отзывается.
- Имя outbound — тег в клиентских файлах. Дополнительный домен ссылок не создаёт CDN.
- Сброс статистики перезапускает Xray. Индивидуальный сброс сохраняет статистику остальных пользователей.

Настройки сервера разделены на домен/сертификат/порты, копии, обслуживание,
отображение, администраторов и диагностику. В технических экранах протоколов,
карточках пользователей, HWID, шаблонах, DNS и маршрутах кнопки описывают действие.
Данные подключения сохраняются без подмены и обрезания. Запросы ввода поясняют
формат и последствия изменения.

Изменения с немедленным влиянием на подключение или данные открывают экран
последствий с кнопками применения и отмены. Подтверждение привязано к пользователю,
текущей конфигурации и одноразовому токену с временем жизни 5 минут; повторное,
отменённое, просроченное или устаревшее подтверждение не выполняется.
Ввод нового значения остаётся явным действием пользователя после пояснения.
В классическом интерфейсе прежний порядок действий сохранён.

### Вложенные разделы

Полная [карта меню](menu-coverage.md) перечисляет 56 построителей экранов и
уведомлений и 57 запросов ввода. Для каждого определён модуль представления.

- Карточка VLESS: подключение/QR/резерв, файлы приложений, доступ/срок/устройства,
  личные шаблоны с текущим выбором. Секретные ссылки находятся в подключении.
- WireGuard / Amnezia: устройства, параметры экспорта, протокол, сетевая политика.
  В устройстве отдельно файл/QR, доступ и сетевые настройки. Кнопки, ответы ввода
  и подтверждения сохраняют номер сервера, даже если позже открыт другой.
- OpenConnect: подключение, пользователи, настройки. DNS: адреса/панель, доступ,
  вышестоящие резолверы, восстановление.
- PAC: ссылки, свои домены, источники. В списках отдельно записи и операции
  импорта/экспорта/очистки. Импорт CSV явно обозначен как замена всего списка.
- Защита IP: блокировки, исключения, анализ, автоматизация. Журналы разбиты на
  страницы; очистка и её расписание находятся в отдельном разделе.
- Остальные протоколы, зеркало, обновления, язык и служебные операции получили
  описания назначения, состояния и понятные кнопки возврата.

Просмотр WireGuard не меняет глобальный `wg_instance`. Для его фильтрации исправлен
выбор флагов: WG1 использует `wg1_exchange` и `wg1_blocktorrent`, WG0 — свои.
Эти правила применяются лишь при явном изменении настройки пользователем.
PAC открывает один экран без повторной пустой отправки. Длинные имена шаблонов
передаются через ограниченные по времени ссылки на callbacks в сессии пользователя.

## Переключение интерфейса

Кнопка **Старый интерфейс** сохраняет выбор пользователя. В старом меню первой
строкой появляется **Новый интерфейс**. Команды `/classic` и `/newui` позволяют
переключиться из любого раздела. `/menu` открывает выбранный вариант.

Предпочтение хранится по Telegram ID пользователя в `/config/bot-ui.json`, отдельно
от PAC и сетевых настроек. Оно переживает перезапуск PHP/контейнера и не меняет
выбор других пользователей. Запись защищена блокировкой файла; неверный формат
настроек открывает старый интерфейс и не перезаписывается автоматически.
Старые сообщения с кнопками нового меню после отката возвращают к старому меню,
не сбрасывая выбор. Старые callback-команды продолжают работать.

Реализация: `app/eternal_ui.php` и `app/eternal_status.php`, подключённые как traits
в `Bot`. Главное меню не опрашивает SSH и сертификаты. Файлы с данными доступа,
как и прежде, отправляются только в личный чат нажавшего пользователя.

## Проверка

В PHP 8.1 с расширениями рабочего бота:

```sh
php eternal/test-ui.php app/bot.php
php eternal/test-client-exports.php app/bot.php
php eternal/test-status.php app/bot.php
php eternal/test-admin-ui.php app/bot.php
php eternal/test-profiles-ui.php app/bot.php
php eternal/test-wg-ui.php app/bot.php
php eternal/test-lists-ui.php app/bot.php
php eternal/test-services-ui.php app/bot.php
php eternal/test-egress.php app/bot.php
php eternal/test-cdn.php app/bot.php
php eternal/test-funnel.php app/bot.php
```

`test-ui.php` включает базовые проверки `test-direct443.php`. Telegram и SSH
подменены, предпочтения записываются только во временную папку. Проверяются
переходы меню и возврат на предыдущий шаг, обновление статусов с подменённым источником,
сохранение и откат, изоляция пользователей, старые callbacks, двенадцать вариантов
экспорта, выбор инструкции по режиму, отдельную пересылаемую инструкцию,
неполную доставку и ограничения Telegram.
Сетевые настройки не меняются; сообщения тестами не отправляются.

`test-admin-ui.php` проверяет технические разделы, маршруты кнопок, сохранность
выдачи, фильтры, жизненный цикл подтверждений, старый интерфейс и отдельный сброс
статистики. Все действия сервера и Telegram в нём подменены фикстурами.

Тесты вложенных разделов проверяют доступность исходных действий после группировки,
сохранность клиентских ссылок и файлов, текущие значения, ограничения Telegram,
откат интерфейса и привязку WireGuard к нужному серверу через отдельные запросы.
Сетевые операции подменены; проверки не переключают живые службы.
